## 📊 Overview
Built an end-to-end HR Analytics dashboard in Power BI to monitor key employee KPIs, track productivity and attendance trends, 
and identify top performers. This solution helps HR and management take data-driven decisions for appraisals and resource planning.

## ✨ Features
- Total Employees, Average Performance Score
- Department-wise Performance Comparison
- Monthly Performance Trend
- Top 5 Performers
- Attendance & Productivity Analysis
- Filters by Department, Role, and Month

## 🗂️ Files in this Repo
- `Empolyee_dashboard.pbix` - Main Power BI dashboard file

## 🛠️ Tools Used
- Power BI Desktop
- Excel / CSV for data cleaning
- DAX for measures

## 🔍 Key Insights
- Identified low-performing departments
- Tracked monthly performance improvement
- Helped in decision making for appraisals

## 🚀 How to Run
1. Download the .pbix file
2. Open in Power BI Desktop
3. Refresh data if needed
